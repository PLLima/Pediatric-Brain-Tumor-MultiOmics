# Brain-Cancer-Prediction-Model
Interpretable prediction AI model capable of discriminating genes in the localization of DIPG (Diffuse Intrinsic Pontine Glioma) tumors with the aim of developing targeted therapy.

## Documentation
The core methodology, including handling of $p \gg n$ regime, class imbalance, and integration of multi-omics data (GE and CGH), is documented extensively in the accompanying PDF reports:
- **`reports/rapport.pdf`**: Detailed theoretical foundation, EDA, and statistical robustness analyses of the prediction pipelines (SGCCA, Cooperative Learning, Multinomial Logistic Regression).
- **`reports/pipeline_cooperative.pdf`**: Implementation specifics and sequential workflow of the `NB10` pipeline.
- **`reports/RECAP_METHODO_NB04_NB10.md`**: Summarized breakdown of different modeling approaches and their results.
